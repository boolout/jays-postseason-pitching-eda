6. Methods and caveats

Data note: Pitch and plate-appearance views are calculated from the supplied CSV files. Cluster assignments and cluster-level results are reported from the attached group analysis script and write-up; those cluster labels are not included in the original data ZIP. The ZIP did not contain README_data_dictionary.md or all originally named pre-aggregated tables, so definitions below state how this dashboard operationalizes the measures.
How to read the metrics

Whiff rate: swings marked as whiffs divided by swings. Bars use a 95% Wilson interval calculated from the displayed counts.

Pitcher ahead: the supplied reached_pitcher_ahead flag is used for plate appearances; the supplied pitcher_ahead_count flag is used for pitch-level views. A two-strike count is treated as a pitcher-favorable count.

Out of zone: outside_strike_zone marked true among pitches thrown while pitcher_ahead_count is true.

Center-zone home runs: zone 5 is used as a simple center-of-zone proxy; home runs are divided by pitches in zone 5 and multiplied by 100.

Strikeout rate: plate appearances ending in strikeout for the pitch type of the final pitch, per 100 pitches of that type.

Intervals: approximate 95% Wilson confidence intervals for whiff rate; computed in the browser from the supplied swing and whiff counts.

Small sample: pitchers below the supplied 50-pitch threshold are visually muted and excluded from the sorted rank position.

Important limitations

This is one postseason, with uneven opponents, roles and exposure. Small denominators create wide uncertainty. Location and count effects are descriptive associations. Pitch choices are not randomly assigned, so this dashboard cannot show that a strategy caused an outcome. No numbers in the provided CSV files were changed.
